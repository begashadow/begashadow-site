# BEGA Shadow Resistance — installation

Cette version corrige trois points :

- bannière horizontale au lieu d'une grande image plein écran ;
- navigation visible et adaptée au smartphone ;
- lien Administration visible tout en bas du site.

## Installation

1. Décompresse le ZIP.
2. Envoie tous les fichiers à la racine de la branche `Site_v2`.
3. Remplace les fichiers existants.
4. Ne supprime pas le fichier `CNAME`.
5. Attends le nouveau déploiement GitHub Pages.

## Console

Ouvre `https://begashadow.com/admin/`.

La console est Pages CMS. Connecte-toi avec GitHub, choisis :

- compte : `begashadow`
- dépôt : `begashadow-site`
- branche : `Site_v2`

Tu pourras modifier la bannière, la sortie, les plateformes et les réseaux.

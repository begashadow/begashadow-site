# Installation — BEGA Shadow Resistance V5

Cette version utilise directement l'image fournie comme visuel principal.

Fonctions :
- introduction animée BEGA de 3 secondes ;
- site responsive ordinateur et smartphone ;
- bouton Écouter INTRO BEGA ;
- liens YouTube, Spotify, Facebook, Instagram et Contact ;
- page Streaming ;
- lien Administration en bas du site.

## Installation

1. Décompresse le ZIP.
2. Téléverse tous les fichiers à la racine de la branche `Site_v2`.
3. Remplace les anciens fichiers.
4. Vérifie que `.pages.yml` est bien présent à la racine.
5. Attends le déploiement GitHub Pages.

Le domaine reste configuré par le fichier `CNAME`.

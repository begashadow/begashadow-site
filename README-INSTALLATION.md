# Site mobile BEGA Shadow Resistance

Version optimisée smartphone.

Fonctions :
- intro de 3 secondes ;
- affiche plein écran ;
- bouton Écouter cliquable ;
- YouTube, Spotify, Facebook, Instagram et DistroKid cliquables ;
- contact par e-mail cliquable ;
- affichage centré sur ordinateur.

Installation :
1. Décompresse le ZIP.
2. Téléverse tous les fichiers à la racine de la branche `Site_v2`.
3. Remplace les anciens fichiers.
4. Attends le déploiement GitHub Pages.

Important :
Le bouton Spotify est actuellement dirigé vers Spotify.
Quand tu retrouves l'URL exacte de ta page artiste Spotify, remplace-la dans `index.html`.

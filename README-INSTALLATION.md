# BEGA Shadow Resistance — V10 Poster

Cette version :
- garde l'affiche entière au centre ;
- place le vrai bouton Écouter directement sur l'affiche ;
- place les vrais boutons YouTube, Spotify, Facebook, Instagram et Contact sur l'affiche ;
- masque les anciens boutons imprimés pour éviter les doublons ;
- utilise le tag BEGA pendant l'intro de 3 secondes ;
- fonctionne sur ordinateur et smartphone.

Installation :
1. Décompresse le ZIP.
2. Téléverse tous les fichiers à la racine de la branche Site_v2.
3. Remplace les anciens fichiers.
4. Attends le déploiement GitHub Pages.

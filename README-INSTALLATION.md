# Installation du site BEGA

1. Décompresse le ZIP.
2. Envoie tous les fichiers à la racine du dépôt GitHub `begashadow-site`.
3. Conserve ton dossier `assets` actuel.
4. Vérifie que l'image `assets/bega-hero-mobile.png` existe.
5. Dans GitHub Pages, utilise la branche qui publie actuellement le site.

## Administration

Ouvre :

https://begashadow.com/admin/

Puis clique sur **Ouvrir la console** et connecte-toi avec GitHub.

La console permet uniquement de gérer :

- la prochaine sortie ;
- les plateformes de streaming ;
- les réseaux officiels ;
- l'adresse e-mail.

Pour ajouter une plateforme, clique sur **Ajouter** dans la section
**Plateformes de streaming**, choisis une icône, colle le lien et active **Afficher**.
